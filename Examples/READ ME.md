# Original development study: “A quiet song”

This eight-bar melody and short text were generated for this development build. It is not one of the choir's named hymns and is not presented as a stylistic or musical-quality benchmark. No third-party hymn melody, recording, or lyric was copied into this example.

The example has 22 source melody events, C major, 4/4, quarter-note tempo 82, and Soprano / Alto / Lower voices. The included `.hymn` is a working draft, not an approved choir version. MusicXML and MEI reflect the same structured score. There is no sample engraved PDF because the native PDF path was not run here.

Generated MP3 demonstrations are in the original downloadable source archive, not checked into this repository. To regenerate WAV practice tracks locally, run:

```sh
swift run -c release hymn-cli demo /tmp/hymn-demo
```

Compare the full-choir WAV with an isolated part and its emphasized version. All audio includes a one-bar count-in. “Emphasized” retains the other parts at reduced gain. The sound is a simple sample-free, piano-like synthesizer, not a sampled instrument or separate piano accompaniment.

These sounds were generated by the shared Swift core. **FFmpeg**, not the application's JavaScriptCore MP3 integration, encoded these particular downloadable MP3s. The examples therefore demonstrate generated sound and mix differences but do not validate the native app's MP3 export.
